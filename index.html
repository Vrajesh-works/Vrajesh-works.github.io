01

BindBench

AI binding-affinity screening platform for small biotech labs. Create a project, add protein targets and a compound library, and BindBench ranks every candidate using the Boltz-2 model, with results you can browse, filter, and export.

  • Problem: small labs lack an easy way to run structure-based screening without ML infrastructure.
  • Solution: a project-based workflow that takes targets and compounds in and returns a ranked, exportable candidate list.
  • Engineering: typed full-stack app with a Postgres schema managed by Drizzle and pgvector, deployed on Vercel.

03 // HOW I WORK

From idea to live demo

A repeatable process that keeps projects finished, documented, and usable by someone other than me.

Frame the problem

Pick a real user and a concrete pain point before writing code.

Build the core

Get the data pipeline or model working end to end first, then layer features.

Polish the interface

Make it clear and demo-ready, so the value is obvious in under a minute.

Ship and document

Deploy to free hosting, write the README, and keep the source public.
